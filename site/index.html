evals for agent skills

Know what your skills actually do.

An agent does not do the same thing twice. skill-evals runs your skills across the scenarios you care about, in a real coding agent, and scores each run against what you defined as success. Change a skill, run it again, and see what the change did.

$ npx skill-evals run --a none --b ./skills
Get started

Runs are unattended and have full permissions in the agent. Only run prompts you wrote or read.

Reading a skill is not running it

understand

What it does, not what it says

A language model can load a skill on one run and ignore it on the next. Run each scenario several times and see what happens, and how often.

define

Say what success is

Write down what a good result looks like for each scenario. That turns "it seems better" into a benchmark you can score against.

change

See what an edit did

Reword a description, add a rule, swap the model. Run the same scenarios again and compare the scores, before you merge.

How it works

01 · write a case

A scenario and its checks

A case is a folder: the prompt a user would type, and a JSON list of checks that say what a good result is. No test code.

02 · run it, more than once

A real agent, a clean home

Each case runs several times, with and without the skill. Every run starts your coding agent in a throwaway home directory, so your own settings and installed skills stay out.

03 · read the score

0 to 1, with a pass bar

Checks roll up to a score for each case and the suite, and every answer is saved so you can see why. Set a minimum and the command fails under it.

Three kinds of check

Deterministic

Did the skill load? Was a tool called? Does the file exist, and does it match? Scores 0 or 1, the same every time. 

{ "type": "skill_loaded",
  "skill": "commit-message" }

Decision model

You define the answers and what each is worth. The model returns a probability for each, and the score is computed from them. 

{ "type": "decision",
  "question": "Avoids jargon?",
  "expect": "yes" }

Judged

A model grades the answer against a rubric you write in plain text, for what a pattern cannot see. 

{ "type": "judge",
  "rubric": "Keeps the meaning." }
