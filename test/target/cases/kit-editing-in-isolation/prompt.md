# A skill for release notes

Write a new skill named `release-notes` at `skills/release-notes/SKILL.md`,
in the same layout as `skills/triage/SKILL.md`: front matter with `name` and
`description`, then the steps. It turns a list of merged changes into release
notes.

Before you write it, start a subagent to do the job once without the skill,
as a baseline, and read what it did. Write the skill after that, and change no
other file.
